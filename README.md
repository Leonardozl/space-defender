# 🚀 Space Defender

Um jogo simples desenvolvido em HTML5, CSS e JavaScript puro.

O objetivo é controlar sua nave espacial, destruir as naves inimigas e alcançar a maior pontuação possível.

## 🎮 Como Jogar

### Controles

| Tecla | Ação |
| --- | --- |
| ⬅️ Seta Esquerda | Mover para esquerda |
| ➡️ Seta Direita | Mover para direita |
| 🚀 Espaço | Atirar |

### Objetivo

- Elimine as naves inimigas.
- Ganhe 10 pontos por inimigo destruído.
- Evite que os inimigos alcancem a parte inferior da tela.
- Tente bater seu recorde.

---

## ✨ Recursos

- Sistema de pontuação.
- Reinício automático do jogo.
- Tela de Game Over.
- Nave controlada por teclado.
- Inimigos gerados aleatoriamente.
- Compatível com navegadores modernos.

## ☁️ Publicando no GitHub Pages

### 1\. Criar repositório

Crie um novo repositório no GitHub chamado:

space\-defender

### 2\. Enviar os arquivos

Faça upload do arquivo:

index.html

### 3\. Ativar GitHub Pages

Acesse:

Settings → Pages

Em **Build and deployment**:

- Source: Deploy from a branch
- Branch: main
- Folder: /root

Clique em **Save**.

### 4\. Acessar seu jogo

Após alguns minutos o GitHub gerará uma URL semelhante a:

[https://SEU\-USUARIO.github.io/space\-defender/](https://SEU-USUARIO.github.io/space-defender/)

Seu jogo estará disponível online gratuitamente.
